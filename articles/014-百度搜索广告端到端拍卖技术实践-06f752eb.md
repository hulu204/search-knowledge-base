广告拍卖技术是在线广告检索系统区别于推荐系统与通用搜索引擎的核心特征之一。其核心挑战在于，如何在信息不完全的条件下，通过机制设计实现分配效率或平台收益的最优化。在百度搜索广告系统中，拍卖算法长期构建于现代拍卖理论基础之上，并依赖于人工设计的启发式规则。近年来，随着在线广告市场的持续发展，广告主的营销目标日趋多元、行为策略越发复杂，同时广告平台也需兼顾用户体验、广告主回报和平台收益的三方平衡，而非单一优化目标。这使得实际广告拍卖问题的复杂性远超传统拍卖理论的经典博弈模型，基于简化假设推导出的规则算法，在实际环境中的表现仍存在显著优化空间。

因此，如何充分利用在线广告所具备的海量检索与行为数据，设计更贴合真实业务场景的拍卖机制，已成为一项极具价值的研究课题。本文将以百度搜索广告为背景，分享我们如何从端到端的数据驱动方法出发，逐步推进至生成式拍卖的技术演进路径与实践思考。

**广告拍卖问题挑战与历史技术演进**

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugwzI9FvpAWnWXEmBLxW22gCW0F5YTs4JNezzlRibibvKCZcqxPj2CxwSQfRvbObYqwfP4HFj1zwnmbQ/640?wx_fmt=png&from=appmsg)

结合百度搜索广告的业务特点，广告拍卖机制面临的核心挑战可归纳为以下几点：

* ****多物品拍卖问题****：在百度搜索广告场景下，单次检索对应多个广告位填充，所以它本质是一个多物品拍卖或者组合拍卖问题。传统做法一般是采用分位次拍卖的方式，按照位次由低到高逐个进行拍卖。这种做法实现简单，但无法充分考虑不同广告间的外部性影响，具体来说，做后置位广告分配时可以考虑到前置位对其的影响，但做前置位广告分配时无法预估后置位对其的影响，因此导致拍卖的结果并非全页面最优[1,2]。当广告位数量增加时，这种外部性效应会更加复杂。
* ****重复拍卖问题****：在线广告系统面临的单日检索量往往过亿，甚至几十亿、上百亿，所以在线广告拍卖是一个重复拍卖问题，目标是全局最优，而非单次结果最优。传统做法采用单次拍卖最优建模来近似全局拍卖最优问题的核心假设在于，重复拍卖中每次竞价通常被视为独立事件，但这显然不符合真实情况。对于用户来讲，不同检索行为存在关联；而对于广告主而言，在重复拍卖下可以针对不同时段采取策略性的出价或预算行为，并非锚定为单次竞价。因此，这种独立性假设的失效，直接导致传统建模在全局最优目标面前出现系统性偏差。
* ****多目标优化问题****：广告平台的目标并不是一味追求收入最大化，而是作为 “中介” 对多方诉求进行协调，平台收入、用户体验、广告主生态三大目标间的冲突是广告拍卖建模直面的核心问题之一[3-5]。若仅追求收入，会失去用户和广告主的长期信任；若仅强调用户体验，会因收入不足难以维持服务；若忽视广告主生态，则会失去市场活力。因此，广告拍卖问题本质是一个多目标优化问题，只有将多目标优化贯穿于拍卖设计的始终，在线广告生态才能实现长期可持续发展。
* ****激励兼容问题****：广告拍卖需要考虑的另一个关键问题是如何让广告主如实地披露真实信息，比如对广告位的真实估值、目标成本等。在面向激励兼容问题进行拍卖机制设计时，往往面临“理想与现实”冲突。主流的GSP拍卖[6-8]虽简单易落地，却非完全激励兼容：广告主可通过 “策略性出价”获利，如低报估值仍保排名、高报估值挤走对手，导致 “如实出价者吃亏”，破坏公平性。而VCG拍卖[9-11]等机制理论上可实现 “占优策略激励兼容”，但其付费计算规则过于复杂，对于广告主的数据披露也较黑盒，难以落地[12,13]。

多年来，我们持续围绕上述问题挑战对广告拍卖问题进行建模优化，历史上具有重要意义的技术演进如下表所示。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugwzI9FvpAWnWXEmBLxW22gCxKynBbSnvdccCfcWzOGhwyjmZbsXDfW7ic1uuSA0P844SgpppQ44jCA/640?wx_fmt=png&from=appmsg)

整页拍卖的成功上线，是我们从单物品拍卖建模迈向多物品拍卖建模的关键跨越，标志着激励兼容的VCG机制在搜索广告场景的首次成功落地，具有重要的里程碑意义。这一成果也将基于现代拍卖理论的算法设计技术路线推向了新的高度。然而，由于整页拍卖的计算复杂度较高，在工程实现中需综合考虑资源消耗与系统效率，因此在实际部署时采取了部分折衷方案，其效果尚未达到整页最优。此外，针对重复拍卖、多目标优化等复杂问题，在上述技术框架下仍缺乏系统性的解决方案。

本文接下来将重点介绍我们在端到端拍卖机制设计上的探索。在整页拍卖的基础上，通过引入端到端数据驱动的学习方法进行拍卖机制设计，在重复拍卖、多目标优化等长期存在的技术挑战上取得了显著突破。

## 3.1 自动拍卖机制——面向重复拍卖问题的初代尝试

在探索初期，为更有效地应对重复拍卖场景，并适应广告供给与用户流量的动态变化，我们借鉴已有研究成果[14]，提出了一种自动拍卖机制。该机制能够依据全局目标进行自适应调整，实现了拍卖策略的动态优化。

具体而言，我们首先对拍卖算法的核心参数按流量类型进行细分，使得同一参数可针对不同类型流量赋予不同取值。通过这一方式，一个参数向量即可唯一定义一种拍卖行为。基于此，我们将整个拍卖系统视为一个超参数优化系统，借鉴神经架构搜索（NAS）[15,16] 的思想，以流量粒度对拍卖机制进行效率调优，从而实现系统整体效率的最大化。在此框架下，我们设计并落地了名为 NMS 的自动拍卖机制，如图2所示。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugwzI9FvpAWnWXEmBLxW22gC5B4unfcGuyqqf2iam6Jsv4TAQibwib1QoymanGbdicUqqHD8d4sAZQ4Kng/640?wx_fmt=png&from=appmsg)

NMS中的核心工作集中体现在两个层面：

1. ****高效机制参数采样算法：****在项目初期，我们采用深度LSTM网络结合策略梯度（policy gradient）算法构建NMS，并取得了一定效果。然而，在实际应用中，该方案逐渐暴露出采样效率低、策略梯度估计方差大等问题，导致训练过程收敛缓慢且不稳定；同时，高维连续的参数空间也使得有效探索变得困难，难以在可行时间内获得较优的拍卖机制配置。为此，我们将算法升级为DeepES（深度进化策略），依托其并行采样与黑盒优化能力，显著提升了参数搜索的效率和稳定性。该算法通过部署多个worker并行生成大量候选参数，并依据集中式评估反馈对参数分布进行迭代更新，从而有效应对高维探索难题，实现了更快、更稳定的收敛过程。
2. ****高效机制参数评估体系：****直接通过在线AB实验评估的方式虽然直观，但广告系统的流量与预算通常呈现以天为单位的周期性变化，若每组参数评估需持续一整日，将导致模型训练极其缓慢。此外，NMS输出的参数并不总是优于当前配置，直接上线可能带来真实损失。为解决这一问题，我们搭建了一套旁路部署的线上拍卖系统镜像环境，配合天级日志采样，能够在高保真地复现线上环境的同时，完成对单日整体效果的无损评估，既避免了线上风险，也大幅加速了评估迭代过程。

## 3.2 DeepAuction1.0——更加适配业务发展的多目标优化问题解法

尽管上述自动拍卖机制已通过精细化的流量参数优化，在提升整体拍卖效率上取得了显著的业务成效，但其拍卖函数（RankScore）仍局限于多目标场景下的固定线性形式——这一局限让方案仍存在不小的优化潜力。如前文所述，在线广告拍卖系统的单日流量请求常以亿计，在如此庞大的流量规模下，输入信息与目标之间往往存在复杂的非线性关联。显然，单一的线性公式难以突破形式限制，无法实现全局层面多目标分配的最优状态。因此，我们尝试借助深度神经网络，通过端到端的方式进行大型非线性函数逼近（Nonlinear Function Approximation，NFA），以此更精准地捕捉输入与目标之间的非线性关系，最终从全局最优的视角进一步提升拍卖效率。基于这个动机，我们基于整页拍卖框架通过构建DeepAuction模型来取代原有的线性排序函数。

DeepAuction1.0模型的输入为候选广告序列（页面），输出为获胜广告序列，示意图如图3所示。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugwzI9FvpAWnWXEmBLxW22gClrLaCHicKwMkjVZchscJZCSiaADicG0DrUfoSHSQibrjibZJmlhgVSELVkQ/640?wx_fmt=png&from=appmsg)

上述模型实践中的一些设计考虑：

* ****优化目标****：模型预测在当前PV下每个页面的胜出概率。优化目标可以表达为：

  ![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugwzI9FvpAWnWXEmBLxW22gCrpq9od0zkQ2Qz5FUGf96sU67MLkRhJkATGKCwFibIIv2SicIicO0CicceQ/640?wx_fmt=png&from=appmsg)

* ****帕累托序列压缩（Pareto Sequence Compression, PSC）：****在输入层为了让模型更好地预估获胜序列，我们借鉴多目标优化理论中的非支配解集的概念对所有候选序列进行了序列压缩。具体而言，我们将每个候选序列视为一个解，其在不同目标（如平台收入、用户体验、广告主生态等）上的表现构成目标向量。通过帕累托支配关系，筛选出所有非支配序列，即那些在任何目标上都不被其他序列完全超越的序列，组成帕累托前沿。这一过程显著减少了候选序列的数量，降低了模型的计算复杂度，同时保证了候选集的质量和多样性。实验表明，该方法在提升预估准确性的同时，将推理效率提高了2.5倍。
* ****全局目标和约束量化****：上述优化目标和约束均基于全局考虑，因此在训练阶段通过单日全量样本来采样构建batch，并通过计算batch层级的损失函数，以有效逼近对全局优化目标和约束的刻画。
* ****广告计费****：采用类VCG拍卖的方式对广告进行计费，获胜序列中任意广告的计费可通过获胜序列与不含该广告的最优候选序列的收益之差进行计算。

## 3.3 DeepAuction2.0——“生成-判别”两阶段范式的生成式拍卖

DeepAuction1.0上线后，排序函数从人工设计的线性形式升级为基于全局多目标端到端学习的非线性模型，不仅提升了用户体验，也使分配效率实现了超过8%的提升。然而，在整个拍卖流程中，序列生成阶段仍有进一步优化的空间。一方面，序列枚举的空间规模超过千万量级，实时全枚举对系统响应时间构成巨大挑战，因此线上必须严格限制枚举总数；另一方面，受限于枚举数量，线上采用的是一种基于单PV效率贪心的启发式枚举算法，该策略未与全局多PV优化目标对齐，导致枚举效率存在浪费。基于上述原因，我们将序列枚举阶段重新定义为从广告候选集生成广告序列的过程，并引入模型直接生成候选序列，再结合前述DeepAuction1.0模型作为判别器，共同构建出一个“生成-判别”两阶段的拍卖新架构，如图4所示。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugwzI9FvpAWnWXEmBLxW22gCxHHMLjrkfWu33MUtJESQjiaVBUmHc3Wj6RwakwoUuXFMQwOKU0gd1fQ/640?wx_fmt=png&from=appmsg)

生成式拍卖模型的构建涉及以下几个关键环节：

* ****广告序列生成建模：****将广告序列生成过程建模为带约束的马尔可夫决策过程（CMDP），基于候选广告集合、全局目标及约束条件，结合已生成的前序广告信息，逐位次生成序列中的每个广告，直至达到预设序列长度或生成终止符。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugwzI9FvpAWnWXEmBLxW22gCxSKooFsvKicVJm2x2v7KG4yk1cZFP5XsJG77SgcOLZWefoFyqmef9dw/640?wx_fmt=png&from=appmsg)

* ****广告序列级业务规则约束：****生成模型不仅需与判别模型（DeepAuction1.0）在优化目标和约束条件上保持一致，还必须确保生成的广告序列符合业务规则，例如禁止同类广告重复出现。在实际实践中，序列级业务规则多达10余项，共计4类。为此，我们主要从如下两方面保证生成可行序列：

+ ****选用Encoder-Only结构****：我们对比了Encoder-Decoder、Encoder-Only和Decoder-Only三类主流大模型结构，最终采用改进的Encoder-Only架构。因其能更有效地学习组合约束，避免如Cross-Attention或Self-Attention机制隐式学习规则所带来的困难。我们将已生成广告以向量形式与输入序列拼接，共同输入Encoder，显著提升了训练效率，尤其在少样本场景下表现优异。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugwzI9FvpAWnWXEmBLxW22gCWe8pSic7bbFKOaEWyTDjWrJZOORRqhnnjk0iaM62Rd96dQUFGJaEelCg/640?wx_fmt=png&from=appmsg)

+ ****引入Rule Mask机制****：在Encoder基础上额外添加规则掩码层，显式屏蔽违反业务规则的token生成，保障序列合法性。

* ****训练流程：****生成式拍卖属于新兴任务，缺乏现成预训练模型与监督标签。我们最终构建了“Pretrain-SFT-RL”三阶段训练框架。

+ ****Pretrain（预训练）****：以监督学习方式冷启动模型，学习历史获胜广告的生成模式。该阶段训练成本低，可充分利用大量历史样本。
+ ****SFT（监督微调）****：从小批量样本中通过线性规划求解最优序列作为“示范样本”，用于模型微调。需权衡两点：一是线性规划计算复杂，需控制样本规模；二是所得最优解仅为局部样本下最优，需结合探索策略以提升生成多样性。
+ ****RL（强化学习）****：将基于全局业务目标寻优的判别模型作为奖励模型，采用DDPG算法进行强化学习，激励模型探索未知序列，增强泛化能力。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugwzI9FvpAWnWXEmBLxW22gCCVR0XtribXficEUTjXMzUxO9U9sBwPibEXTMlG9JZ8Eg7wZeNkGBOMdQA/640?wx_fmt=png&from=appmsg)

* ****推理优化：****为保障线上服务的实时性，我们从工程实现层面对推理链路进行了专项优化。

+ ****多CUDA Stream推理****：将单CUDA stream推理升级为多CUDA Stream推理，推理性能优化23%，吞吐提升100%。
+ ****算子融合****：常见算子采用TRT自动算子融合，特殊业务算子采用手动算子融合并重写计算逻辑，推理性能优化30%，吞吐提升33%。
+ ****模型量化****：对部分FP32精度的矩阵计算转成TF32方式，在精度损失可控的前提下，推理性能优化15%。
+ ****去padding****：从原先固定长度sequence推理转成动态长度sequence推理，性能优化58%，吞吐提升120%。

“生成-判别”两阶段范式的生成式拍卖模型上线后，在满足全局业务约束基础上，分配效率提升3%以上，相关工作已整理为论文发表在AAAI 2025[17]，更多信息见论文内容。

## 3.4 DeepAuction3.0——端到端生成式拍卖

采用上述两阶段生成式拍卖机制后，广告检索系统的扩展性迎来了更广阔的发展空间与新的技术挑战。一方面，该范式能够直接基于候选广告集合生成最优序列，这种能力可进一步扩展至上游更广的候选范围，从而突破传统多级漏斗式检索架构，实现扁平化与一体化检索，与快手近期提出的OneRec[18]设计理念相契合。另一方面，通过引入大规模离散特征、持续优化模型结构与生成能力，上述“生成-判别”分离的架构可进一步演进为“生成即拍卖”的端到端一体化新范式。当前，我们正围绕这两大方向持续探索，其中“生成即拍卖”的端到端模型已在搜索部分场景成功落地，并计划逐步扩展至全场景应用。
