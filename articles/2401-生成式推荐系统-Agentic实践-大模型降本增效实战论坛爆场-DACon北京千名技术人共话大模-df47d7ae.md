主题演讲精彩回顾

![]()

DataFun技术社区创始人王大川开场致辞，并介绍了两天大会的内容亮点，策划思路，重磅嘉宾，以及作为技术社区的价值主张模式，为业界的技术发展，提供交流平台，传播最新的技术实践经验。

![]()

复旦大学教授、博导，上海市数据科学重点实验室主任肖仰华分享了以数据为中心的大模型行业发展演进路径话题。肖老师长期从事大数据、 知识图谱研究。发表 CCF-A 、B 类等论文 200 余篇。出版学术专著与教材三部。 完成五十多项政府及人工智能头部企业研发项目。荣获包括华为、阿里、美团等机构授予的科研奖项二十多项。担任 Applied Intelligence 等多个国际期刊副主编或编委。本次演讲中，从大模型发展趋势开始讲起，介绍了面向AI的数据产业的高质量发展需要资源、技术、模式、制度并进。同时提出了一个很关键的话题，那就是我们需要怎样的数据方法论才能推动大模型行业落地？在模型使用过程中，如何做好支持储备，如何提升理解能力，以及学校该如何推进大模型的研究与落地，都给出了观点，现场收到听众的一致好评。

![]()

阿里云智能集团计算平台事业部产品负责人徐晟分享了《阿里云OpenLake：AI时代的全模态、多引擎、一体化解决方案》话题。阿里云OpenLake解决方案，是基于开放可控的数据目录服务Data Lake Formation（DLF）构建的大数据搜索AI一体化的全模态智能体数据解决方案。OpenLake提供企业级安全管理的开放湖仓，通过Omini Catalog（5类数据目录）支持开源格式的数据表（Paimon、Iceberg）、开源数据格式（Parquet、ORC、Avaro）和各类数据文件（多媒体、数据等），支持大数据、搜索和AI的多引擎平权同一份数据协同计算，通过DataWorks的OpenLake Studio 提供 IDE 或 Notebook 方式的Data和AI的集成开发，支持多任务可视化调度和大规模高并发任务调度保障。提供OpenLake Agent / MCP数据访问能力，支持全模态智能体访问，打造Agentic Data 的新湖仓。

在行业实践上， OpenLake助力诗悦游戏降本增效，总成本降低38%，计算资源下降17%，以低成本+高稳定性+高性能承接未来各种业务应用。互联网教育企业绚星智慧通过OpenLake让同一份数据支持Flink，Spark，StarRocks多种引擎对接，满足不同场景的用数需求，整体成本降低50%，查询性能提升300%，端到端数据10分钟可见。

![]()

vivo互联网智能平台总经理叶庆文分享了大模型驱动的推荐系统新范式：vivo的实战经验与未来展望话题，围绕生成式AI正加速推动推荐系统的范式演进，从"理解用户"走向"生成内容"，从"精准匹配"迈向"主动创造"，推荐系统的核心能力正在被全面重构。

叶庆文深耕大规模机器学习/推荐系统/计算广告/计算引擎/大模型等领域，全面负责vivo互联网内容推荐、商业变现、应用与游戏分发等多种业务场景，取得突出业务增益，为5亿vivo用户提供极致的智能服务。 

本次演讲结合vivo团队多年深耕商业广告与内容推荐系统的实战经验，深入剖析从深度学习到大模型赋能下推荐算法策略的重构路径，系统分享推荐系统与生成式技术深度融合在vivo互联网业务的实践与落地成果，为行业迈入智能生成驱动的下一代推荐系统提供趋势洞察与前沿参考。介绍了从0到1构建一流高性能和高可用性的推理中台、训练中台、数据中台的实践与成果，也分享了超大规模推荐系统模型，Scaling Law在推荐系统的实践；以及推荐系统与生成式技术深度融合在vivo互联网业务的实践与落地成果。

闭门会议：“Palantir本体论”构建理解业务真相的AI系统

![]()

Palantir市值狂飙的背后，是其将古老的哲学思想——“本体论”转化为强大生产力的结果。它不仅仅是另一个数据分析工具，而是为企业构建了一套“决策操作系统”。这套系统的核心在于，它不满足于处理数据，而是要像企业专家一样“理解”数据背后的业务含义——客户、产品、供应链、风险之间的复杂关系。本次闭门会邀请了多个业界专家深度解构了Palantir的“本体论”实践。
