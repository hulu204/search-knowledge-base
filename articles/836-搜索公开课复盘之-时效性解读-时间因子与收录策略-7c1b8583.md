### 搜索公开课复盘之《时效性解读》

发布日期：2020-12-02

上周五，百度搜索线上公开课如期和大家见面，百度搜索产品经理谢其扬从三个方面：什么是时效性、时效性在百度搜索中的重要性以及如何判断时效性，为开发者们详细解读了时效性的相关内容。

本小鱼对“时效性解读”公开课进行了一场复盘，课程重点、难点、案例...你想了解的都在这里，快来看看吧~

## **一、什么是时效性？**

### 1、时效性是指用户对搜索结果新旧程度的感知。

 

### 2、时效性的重要性：

对于用户来说：在满足需求的前提下，用户天然希望获得相对新鲜的资源。

对于开发者来说：持续生产时效性高的优质内容，有利于获得更多内容分发机会。

 

### 3、时效性内容的分类：

**（1）受时间影响较大的内容**：即对时效性要求较高的内容，比如新闻事件、周期性更新的资源和持续更新的资源。

![](https://zhanzhang.bj.bcebos.com/files/053041606893367.png)

*△天气预报和奖项公布名单都是时效性要求非常高的内容*

**（2）比较稳定的内容**：即对时效性要求相对不高的内容，比如固定答案、长期不变的资源、更新已完结或明确指向的资源。 

![](https://zhanzhang.bj.bcebos.com/files/052551606893442.png)

*△已经完结的电视剧是相对比较稳定、对时效性要求相对不高的内容*

![](https://zhanzhang.bj.bcebos.com/files/082251606893433.png)

*△地址属于相对比较稳定的内容，但地址变更时，需要及时更新最新地址。*

注意：**上述****两类****内容****可能会相互转换，**如北京市政府2019年搬迁到通州新址后，需要及时更新最新的地址或相关的新闻资讯。展现旧地址会误导用户，损害用户体验。

 

## **二、时间因子**

### 1、时间因子是指页面主体内容的产生时间，或者能够辅助用户判断内容时效性的时间。

 

### 2、时间因子的重要性：

符合规范的时间因子可以让用户获得更好的浏览体验，也可以辅助百度搜索策略更精准地判断内容时效性。

![](https://zhanzhang.bj.bcebos.com/files/094191606893517.png)

*△在问答详情页有最新回复时间；在内容详情页有内容发布时间*

### 3、时间因子包含以下三种类型：

内容发布时间（PubDate）、内容更新时间（UpDate）、最新回复时间（IrDate）

 

### 4、根据不同的页面类型，用户需要参考的时间不同。根据以下不同的页面类型，建议优先提交不同的时间因子。

|  |  |  |
| --- | --- | --- |
| 页面类型 | 示例 | 时间因子 |
| 首页 | 新浪、网易等门户首页及频道页 | 最新内容更新时间必填 |
| 列表页 | 小说/视频页、搜索结果页、个人主页、专题页等 | 最新内容更新时间必填，  专题页可以补充发布时间 |
| 详情页 | 纯内容页：文章、视频等 | 内容发布时间必填，  可以补充内容更新时间 |
| 异构页面：问答详情页、论坛帖子 | 内容发布时间、内容更新时间、最新回复时间均必填 |

 

### 5、提交方式：

使用 JSON-LD格式在页面中嵌入代码即可，详细标准及提交格式可以参考[《百度搜索落地页时间因子规范》。](https://ziyuan.baidu.com/college/articleinfo?id=2210)

![](https://zhanzhang.bj.bcebos.com/files/050691606893581.png)

*△时间因子提交格式*

## 三、**站点收录**

### 1、百度如何发现网站内容？

百度搜索Spider会主动定期抓取网站内容，同时开发者们也可以在百度搜索资源平台主动提交资源。

开发者们可以通过普通收录工具和快速抓取工具主动提交资源。对于优质的高时效性资源，合理利用收录工具可以缩短爬虫发现网站链接的时间，让百度搜索能及时收录最新的内容资源。

 

### 2、普通收录

普通收录工具可以帮助广大开发者主动向百度搜索推送资源，可以有效缩短爬虫发现链接的时间，**主要包括API提交、手动提交、sitemap、自动推送四种方式。**

![](https://zhanzhang.bj.bcebos.com/files/014541606893626.png)

### 

### 3、快速抓取

快速抓取工具**仅适应****移动端页面及移动端自适应页面****，**可以帮助开发者们向百度搜索主动推送资源，对于高实效性内容推荐使用快速抓取工具，实时向搜索推送资源。

![](https://zhanzhang.bj.bcebos.com/files/070261714273853.png)

### 4、不同收录方式的对比

### 5、建议：

（1）对于受时间影响较大的资源，建议开发者们在保证质量的前提下尽可能生产时效性高的内容，满足用户需求；

（2）[按照《百度搜索落地页时间因子规范》](https://ziyuan.baidu.com/college/articleinfo?id=2210)，在不同的页面类型中提交不同的时间因子，有利于提高站点的展现机会。
