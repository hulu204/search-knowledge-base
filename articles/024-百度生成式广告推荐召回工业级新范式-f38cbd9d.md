**背景**

在广告推荐系统领域，精准捕捉用户兴趣、提供个性化推荐一直是核心挑战。传统方法多依赖手工设计特征与浅层模型，难以充分挖掘用户行为序列中的复杂模式。近年来，生成式模型凭借其强大的序列建模能力，为广告推荐带来了新机遇。从23年至今，生成式推荐（Generative Retrieval）已经逐步成为推荐领域最火热的研究方向。百度信息流广告团队从23年开始投入研究GR方向，本文将深入剖析团队在这一技术上演进路径，阐述各阶段的技术创新，并通过实证分析展示其在工业场景中的应用价值。

聚焦序列推荐场景，简单来说，生成式推荐的任务是利用生成式范式学习序列item之间兴趣迁移关系，能够通过前序序列生成用户下一个兴趣点。值得注意的是，序列中每一个item是一个综合体，而非简单的文本token，以一个视频广告item为例，包含title、品牌、落地页信息、多模信息等，这是与传统的NLP任务的根本差异。因此item的表征是GR中的核心问题，影响后续算法和检索工程设计。综上，GR的两个核心问题是：（1）item如何表征，（2）基于表征如何序列建模，后续技术迭代和演进都将围绕着这两点展开。

**3.1 初期探索：纯文本表征 + LLM建模**

团队初期进行了一些纯文本方案的探索，直接利用LLM进行推荐，具体做法如下：通过文本（标题、落地页等）表示item，伴随着超长的输入是资源和性能开销，导致满足生产环境要求；而后通过短语表示item，比如将广告表示为『传奇游戏』、『xx小说』等，但短语信息丢失结果也不理想；此外要建模item间的关系并非单纯语义关系，与LLM存在着语义鸿沟。

**3.2 第一阶段：Dense表征 + 对比学习度量**

初期探索验证了无法简单将GR当作LLM任务对待，需要考虑对item的压缩表达，以满足性能、信息完备、item关系建模的要求。认识到这一点，团队尝试将item表征为dense向量。首先引入一个小参数量Encoder逐个对item信息进行编码，此时item序列转变成一组向量序列。然后将向量序列输入到 Causal Decoder 中，通过 next item prediction方式完成模型训练，在训练中引入了对比学习，同时Encoder、Decoder同步更新。最终推理阶段，通过Encoder输出item向量构造索引，向量序列输入到 Decoder中获取用户表征，完成ANN召回。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugymiblibrKceSLYzFEhcickK1p19PGhmKSYrf320Cdf8UNLoDhE5xPzgvkiaYcRGpiawXHHJxqSeT4H2zQ/640?wx_fmt=png&from=appmsg)

作为生成式模型在广告推荐领域的初步探索，有效解决了item信息利用和序列关系建模两大关键问题；但也注意到该范式更多依赖Transformer刻画序列，缺少兴趣探索过程，仍然在较大dense空间建模。

**3.3 第二阶段：Sparse表征 + Sparse ID生成**

受Google Tiger框架启发，团队尝试了通过稀疏ID表征item，得益于『item嵌入 + 量化』的前置处理，序列建模能够在有限的离散空间中展开。首先通过商业预训练模型（如Ernie）对广告文本进行嵌入；然后使用RQ-VAE将嵌入向量量化为带有层次结构的ID tuple [L1, L2, L3]；最终将ID序列输入Causal Transformer，通过 next id prediction 建模序列。推理阶段，给定行为序列，模型可自回归地生成下一个可能的广告ID tuple。

Sparse表征巧妙的利用『嵌入+量化』将item转变为ID tuple，使得模型可以在压缩空间上学习用户兴趣转移；但由于『嵌入、量化、序列建模』相互隔离，独立的嵌入和量化不可避免地带来信息损失，该方法难以捕捉用户偏好的精细变化。

**3.4 第三阶段：Sparse-Dense级联表征 + 生成度量一体化**

经过前期的探索，发现单一的广告表征方式难以同时兼顾粗粒度的类别信息和细粒度的特征信息，限制了模型的灵活性和适应性，有没有方法能够兼顾两者？沿着这个思路，团队在今年提出了Cascaded Organized Bi-Represented generAtive retrieval (COBRA) 框架，通过级联的方式巧妙地融合了Sparse ID和Dense向量表示，生成和度量一体训练，兼顾了Sparse和Dense的优点。

**3.4.1 方法设计与创新点**

COBRA通过Sparse ID与Dense向量的级联表征item，交替生成充分发挥两者优势，提升模型的表达能力和预测精度。该范式核心优势在于：

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugymiblibrKceSLYzFEhcickK1p0tsdvURvLI4b3J6sDhxTrXWaaS1lJbqZ81wzC2kT0hXibJFa21Ld7Ow/640?wx_fmt=png&from=appmsg)

**级联 Sparse / Dense 表征及交替生成**

在训练过程中，不同于以往仅依赖Sparse ID或者Dense向量的方法，COBRA交替预测Sparse ID和Dense向量，先预测ID学习分类信息，Dense向量弥补了纯ID方法中的信息损失问题，又以Sparse ID作为条件预更精细的Dense向量，在更小的空间中，降低了dense向量学习的难度，促进两种表示之间的相互学习。

**端到端训练**

通过增加对比学习loss，端到端训练动态学习Dense向量，从而能够兼顾语义和协同信息，捕捉细粒度偏好。

**Coarse-to-Fine的生成策略**

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugymiblibrKceSLYzFEhcickK1pO2yJQBya1b7T1RLrQrF9WBDWsprh00QI6G6e4tdg8ia8DlMaWjibraoA/640?wx_fmt=png&from=appmsg)

在推理阶段，采用粗到细的生成过程。首先，基于用户历史交互序列，利用BeamSearch生成下一物品的Sparse ID。然后，将生成的Sparse ID追加到输入序列中，作为条件进一步生成对应的Dense 向量，捕捉物品的细粒度特征。同时为了实现推荐结果的多样性，引入了BeamFusion机制，结合了Beam Search和近邻检索相似度的分数，在保证推荐精度的同时保证召回广告候选的多样性。

**3.4.2 收益**

**公开数据集：**

在Amazon数据集的三个子集（Beauty、Sports and Outdoors、Toys and Games）上，COBRA展现出了卓越的性能。以Beauty数据集为例，COBRA的Recall@5和Recall@10分别达到了0.0537和0.0725，相比之前的最佳模型TIGER，分别提升了18.3%和11.9%。这一显著的提升表明COBRA在捕捉用户偏好和提供精准推荐方面具有明显的优势。

**工业数据集：**

在百度工业数据集上，COBRA同样表现出了优越的性能。当K=500时Recall为0.3716，相比没有密集表示的变体提升了42.2%。在K=800时，其Recall为0.4466，相比没有稀疏ID的变体提升了43.6%，相比没有BeamFusion的变体提升了36.1%。这些结果充分证明了框架中各个组件的重要性和有效性，特别是在提高推荐的准确性和多样性方面。

**真实上线效果：**

在线A/B测试结果进一步验证了COBRA在实际应用中的价值。在百度广告平台的在线A/B测试中，实现了3.60%的转化率提升和4.15%的平均每位用户收入（ARPU）提升。这些显著的业务指标提升表明，COBRA不仅在离线评估中表现出色，还能够在实际生产环境中带来可衡量的商业价值。

**3.4.3 可视化分析**

**内聚性：**

通过构建广告密集嵌入的相似性矩阵，COBRA展现出了强大的类别内聚性和类别间分离性。这意味着不仅能够将同一类别的项目紧密地聚集在一起，还能将不同类别的项目有效地区分开来，从而在推荐时能够更精准地捕捉用户的兴趣点。

可视化结果也显示，不同类别的广告嵌入形成了明显的聚类中心，这表明COBRA能够有效地捕捉语义信息。

**可控多样性和精度：**

通过在BeamFusion机制中调整系数，COBRA能够在召回率和多样性之间取得良好的平衡。它既能保证推荐的准确性，又避免了推荐结果过于单一。这种灵活性使得可以根据不同的业务需求，调整推荐结果的多样性和准确性之间的平衡。

**工程优化**

“Sparse-Dense级联表征 + 生成度量一体化”的新范式为模型能力带来提升的同时，也对训练框架提出了新的挑战，主要包括：

1、超长序列输入显著增加了显存占用与计算负载；

2、显存资源限制使得单卡 Batch 内的负采样规模受限；

为应对上述挑战，我们在训练框架中引入了多项关键优化策略，以提升训练效率。

**4.1 序列Packing**

由于不同用户行为序列与 item 内容在长度上存在显著差异，传统静态 Batch + Padding 的方式会引入大量无效 token，造成显存浪费与计算冗余。为此，我们引入序列 Packing 技术，将多个变长样本高效打包在同一 Batch 中，显著减少 Padding 占比，从而降低显存开销并提升计算效率。

为应对 Packing 输入序列超长且动态变化带来的显存碎片问题，我们采用固定长度的 Packing 策略：在序列未填满时，通过适量 Padding 补齐，确保显存分配更加稳定，避免频繁申请释放造成碎片化，从而提升整体显存利用效率与训练稳定性。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugymiblibrKceSLYzFEhcickK1p6hALT0JBSjtdugiaDZ8Cswt8bicKwsMDXiajV4Z7FnATkL62QnkD9JOiaw/640?wx_fmt=png&from=appmsg)

**4.2 变长注意力**

在我们的模型中，Encoder 阶段不同 item 之间、Decoder 阶段不同用户序列之间并不需要相互关注，因此整个序列的 Attention 图呈现高度稀疏结构。传统做法中通过 Mask 区分不同子序列，虽能实现逻辑隔离，但仍存在大量冗余计算与显存浪费。

为此，我们引入 FlashAttention 的变长 Attention 计算机制，通过显式指定每条序列的有效长度，直接跳过无效计算区域，避免传统显式 Mask 带来的冗余开销。同时，FlashAttention 的 分块计算方式 能显著降低显存使用，有效支持长序列训练。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugymiblibrKceSLYzFEhcickK1pbIvibZrZqtricjCM55cMbhdnVMd9HiaLTUANqvYsOkSRxOtdNa15jS9iaw/640?wx_fmt=png&from=appmsg)

**4.3 全局负采样**

在长序列场景下，单卡 batch size 通常较小，甚至不足以提供足够的负样本，从而限制了对比学习的效果。为解决这一问题，我们在训练框架中引入了 跨设备的全局负采样机制（Global Negative Sampling），支持在多卡之间共享正负样本信息，显著扩大负采样空间，提升训练稳定性与表征对比性。

![](https://mmbiz.qpic.cn/sz_mmbiz_png/Te8D0eD8ugymiblibrKceSLYzFEhcickK1pVJAxDhO1iabOuia4wbJm95RmJwL1ALkxh1lchJlsGuzibqgQ1JtdnWozg/640?wx_fmt=png&from=appmsg)
