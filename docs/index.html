sgt-kb demo

爬取、切块、索引、混合检索，结果带来源引用

这是公开技术文章知识库的可点开演示。下面用仓库里约 2400 篇公开文章的标题和摘要做检索；完整的 bge-m3 混合检索和全文阅读在本地运行。

1. 爬取公开 URL、RSS，或可选的本机公众号采集。
2. 解析分块按标题树递归切块，在标题和段落边界切开。
3. 索引本地 bge-m3 写入 dense 向量和 sparse 词权重。
4. 混合检索双路召回后做 RRF 融合，可按来源和主题过滤。
5. 带引用结果每条结果保留标题、来源、doc_id 和原文链接。
