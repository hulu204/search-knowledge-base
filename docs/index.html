sgt-kb demo

公开文章离线检索，展示已入库的原始分块

这是离线静态词法检索演示（offline static lexical retrieval），使用公开文章的存储分块导出；词法索引和原文分片按需加载，直接展示完整命中文本并保留来源。Pages 不连接 SQLite，也不运行模型。生产分块导出尚未集成时，本页会明确显示等待状态。

本地完整流水线（与下方 Pages 静态检索独立）：

1. 爬取公开 URL、RSS，或可选的本机公众号采集。
2. 解析分块按标题树递归切块，在标题和段落边界切开。
3. 索引本地 bge-m3 写入 dense 向量和 sparse 词权重。
4. 混合检索双路召回后做 RRF 融合，可按来源和主题过滤。
5. 带引用结果每条结果保留标题、来源、doc_id、chunk_id 和原文链接。
